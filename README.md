# Python Course-End Projects

This repository contains Python course-end projects completed as part of my applied Python and data analysis coursework. The projects progress from core Python programming concepts to data cleaning, exploratory data analysis, statistical analysis, visualization, and business reporting.

## Projects

### 1. Adventure Game

A command-line Python adventure game in which the player makes decisions while searching for a legendary treasure.

**Skills demonstrated:**

- Functions
- Variables
- Loops
- Conditional logic
- User input
- Modular programming

**Location:** `adventure_game/`

---

### 2. Customer Order Analysis

A Python project that analyzes customer purchasing behavior using Python data structures and programming techniques.

**Skills demonstrated:**

- Lists
- Tuples
- Dictionaries
- Sets
- List comprehensions
- Sorting
- Business insights

**Location:** `customer_order_analysis/`

---

### 3. Sales Analysis

An exploratory data analysis project using fourth-quarter Australian apparel sales data. The project cleans and prepares the dataset, performs descriptive and grouped analysis, and evaluates sales performance across states, demographic groups, and time periods.

**Skills demonstrated:**

- Pandas
- Data cleaning
- Missing-value and duplicate analysis
- Min-Max normalization
- Descriptive statistics
- GroupBy operations
- Time-series aggregation
- Data visualization
- Business reporting

**Location:** `sales_analysis/`

---

### 4. Marketing Campaign Analysis

A data analysis project examining customer demographics, purchasing behavior, spending, campaign responses, and marketing-channel performance.

The analysis includes data preparation, feature engineering, exploratory analysis, statistical hypothesis testing, correlation analysis, visualization, and business recommendations.

**Skills demonstrated:**

- Pandas
- NumPy
- Data cleaning
- Missing-value imputation
- Feature engineering
- Outlier analysis
- Categorical encoding
- Exploratory data analysis
- Statistical hypothesis testing
- Correlation analysis
- Data visualization
- Business insights

**Location:** `marketing_campaign/`

---

### 5. Incremental Healthcare Data Analysis Capstone

A multi-session capstone analyzing the NSMES1988 healthcare dataset. The project progresses from data preparation and memory optimization through descriptive analysis and visualization.

The capstone examines healthcare utilization, demographics, health status, employment, insurance, Medicaid, education, age, geographic region, and income.

**Sessions:**

- **Session 1:** Data loading, inspection, type optimization, JSON conversion, and dataset preparation
- **Session 2:** Data transformation, descriptive statistics, and updated dataset preparation
- **Session 3:** Detailed healthcare, demographic, regional, and income analysis
- **Session 4:** Data visualization and correlation analysis

**Skills demonstrated:**

- Pandas
- NumPy
- Data type optimization
- Data transformation
- Descriptive statistics
- Pivot tables
- GroupBy analysis
- Matplotlib
- Correlation analysis
- Data visualization
- Analytical reporting

**Location:** `incremental_capstone/`

## Running the Projects

Clone the repository and open it in Visual Studio Code or another Python/Jupyter-compatible environment.

The data-analysis notebooks use relative paths so the repository can be run without relying on user-specific local file paths.

Create or activate a Python virtual environment, install the required libraries, and open the desired `.ipynb` notebook in its project's `notebooks` directory.
