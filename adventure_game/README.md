# 🏆 Adventure Game

## Overview

The Adventure Game is a text-based command-line adventure written in Python. The player takes on the role of an explorer searching for a legendary treasure hidden in an ancient land. Throughout the game, the player must make strategic decisions while navigating either a dark forest or a mysterious cave. Every decision influences the outcome of the adventure.

This project was developed as part of a Python Course-End Project to demonstrate fundamental programming concepts including functions, variables, loops, conditionals, and user input.

---

# Objectives

The objective of the game is to:

- Explore the ancient land.
- Make strategic decisions.
- Successfully locate the legendary treasure.
- Avoid dangerous obstacles.
- Restart the adventure after winning or losing.

# How to Run the Program

1. Open a terminal.

2. Navigate to the project folder.

```bash
cd adventure_game
```

3. Run the program.

```bash
python adventure_game.py
```
