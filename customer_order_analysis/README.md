# Customer Order Analysis

## Overview

This project analyzes customer purchase data for an e-commerce company using Python's built-in data structures. The program processes customer orders, classifies customers based on spending, analyzes product categories, and generates business insights to support data-driven decision-making.

This project was completed as part of a Python Course-End Project.

---

## Objectives

The program performs the following tasks:

- Store customer orders using lists, tuples, and dictionaries
- Map products to categories
- Identify unique product categories
- Calculate total spending for each customer
- Classify customers as High-, Moderate-, or Low-Value Buyers
- Calculate total revenue by product category
- Identify unique products sold
- Find customers who purchased electronics
- Identify the top three highest-spending customers
- Find customers who purchased from multiple categories
- Identify customers who purchased both Electronics and Clothing
- Generate business insights and recommendations
